# Character addition warnings

Before adding a character to this game, check [docs/character-watchlist.md](docs/character-watchlist.md). If the proposed character matches a listed name or a documented alias, tell the user that the character is **"On the list"** before making the addition.

This is a warning, not a prohibition or a requirement for another approval. Continue with an otherwise authorized addition after giving the warning unless the user directs otherwise. Do not remove existing characters because they appear on the list.

Match names without regard to capitalization or an unambiguous navy prefix such as USS or HMS. Preserve significant version qualifiers: II, META, CV, and µ. In particular, the original Laffey (DD-459) and Lexington (CV-2) do not match their listed II versions. The watchlist documents the hull-number aliases for those versions.
